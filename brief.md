\# Projet : Site vitrine — Garage Martin



Site vitrine (HTML/CSS/JS, pas de framework) pour un garage automobile local qui n'a actuellement aucune présence en ligne. Objectif : donner envie d'appeler/prendre rendez-vous, rassurer sur le sérieux du garage.



\## Fonctionnalités V1

1\. Page d'accueil : nom du garage, accroche courte, photo/visuel, bouton "Appeler" bien visible

2\. Liste des prestations (vidange, révision, pneus, diagnostic, carrosserie...) avec description courte

3\. Section "À propos" : présentation de l'artisan, années d'expérience, certifications

4\. Avis clients (3-4 témoignages fictifs pour la maquette)

5\. Horaires d'ouverture + adresse + carte (Google Maps embed)

6\. Formulaire de contact simple (nom, téléphone, message)

7\. Liens réseaux sociaux (Facebook, Google avis)



\## Contraintes

\- Responsive mobile-first (un client cherche "garage près de moi" sur son téléphone dans 90% des cas)

\- SEO de base : balises meta title/description, structure sémantique (header/nav/main/footer), un seul H1 par page

\- Numéro de téléphone cliquable sur mobile (tel:)

\- Pas de framework, vanilla JS

\- Couleurs sobres, rassurantes (pas flashy) — univers "artisan de confiance"
